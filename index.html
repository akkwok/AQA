All-New Model Architecture. Flexible Dual Deployment.

ASUS AISVision 2.0 is an AI-powered machine-vision software toolkit featuring an all-new model architecture and ASUS-exclusive AI technology. It delivers high-accuracy detection, flexible model training, and optimized performance across 4K images, large datasets, and few-shot learning scenarios.

With flexible dual deployment options, AISVision 2.0 adapts to diverse manufacturing environments. It enhances production efficiency and quality control, enabling smarter, AI-driven visual inspection.

Dual Deployment Editions

Standalone or On-Premises — Built for Every Scale

AISVision 2.0 offers two deployment editions to match different production needs. The Standalone Edition enables fast, single-machine deployment with simple setup, ideal for pilot projects and small-scale operations. The On-Premises Edition supports multi-user access and system integration across production lines, making it suitable for large-scale manufacturing environments.

Both editions share the same inference SDK, ensuring seamless integration, scalability, and future expansion.

Integrated AI Solution with ASUS Hardware

Ready-to-Deploy On-Premise AI Infrastructure

The AISVision 2.0 On-Premises Edition can be bundled with ASUS hardware to deliver a fully integrated AI inspection solution. Combining industrial PCs, compute platforms, and AI-vision software, it simplifies deployment and reduces integration complexity.

With a complete hardware-software stack from ASUS, businesses can quickly build a stable and reliable on-premise AI environment. All data and models remain on-site, ensuring enhanced security, data privacy, and compliance with industry regulations.

Flexible AI Model Selection for Different Inspection Needs

Choose the Optimal Balance Between Speed and Accuracy

AISVision provides five core AI algorithms — classification, segmentation, anomaly detection, object detection, and oriented object detection — with multiple model tiers including Lite, Core, Pro, Ultra, and HR. Users can select the optimal model based on inspection requirements, balancing detection accuracy, inference speed, and hardware resources.

With support for the Intel® OpenVINO™ deep learning framework, AISVision delivers efficient CPU-based inference and enables GPU acceleration when higher performance is required, providing flexible deployment options for various manufacturing scenarios.

Accelerated AI Vision Deployment

Move Beyond Traditional AOI and Generic Vision Tools

AISVision accelerates AI-vision deployment from weeks or months to as little as one day, reducing the time and effort required for traditional rule-based AOI setup. Its AI-based models adapt to production conditions, enabling more reliable detection of irregular and multi-angle defects without frequent manual rule adjustments.

Unlike general cloud or open-source vision tools, AISVision provides an integrated platform covering labeling, training, validation, and deployment. Validated across diverse industrial datasets, it delivers accurate, scalable, and cost-efficient AI inspection solutions for smart manufacturing.

FAQ

  • Q1. What operating systems and hardware does AISVision support?

    AISVision is an AI-powered machine vision solution supporting 64-bit Windows 10 and Windows 11 Pro, with C, C++, C#, and Python APIs. APIs are available on both Windows and Linux platforms.

  • Q2. How do I choose between the Standalone Edition and the On-premise Edition?

    AISVision provides flexible deployment options. The Standalone Edition is suitable for single production lines and quick deployment, while the On-premise Edition supports large-scale manufacturing with centralized AI vision management.

  • Q3. Does AISVision support cloud deployment? How secure is the data?

    AISVision uses a secure on-premise deployment architecture. Image data and trained AI models remain inside the customer's environment, helping manufacturers protect sensitive production data.

  • Q4. What licensing options are available for AISVision 2.0?

    AISVision 2.0 provides flexible licensing for AI model training and inference deployment, including USB dongle-based and software-based licensing options.

  • Q5. Can AISVision run without a GPU?

    AISVision supports CPU-based AI inference through Intel OpenVINO technology. GPU acceleration can be added for faster model training and higher-performance industrial inspection.
